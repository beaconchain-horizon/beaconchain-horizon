Independent Verification — Terminal Commands

Every claim in this system can be verified from a fresh terminal. No vendor trust required.

# 1 — Clone the audit repository (public)
$ git clone github.com/beaconchain-horizon/beaconchain-horizon
# 2 — Verify chain integrity (requires running ledger)
$ curl -s localhost:8080/api/v1/chain/info
# 3 — Inspect all blocks and transactions
$ curl -s "localhost:8080/api/v1/blocks?limit=10"
# 4 — Run the TPS benchmark
$ bash tps-report.sh
# 5 — Run the 192-vector security suite
$ ./pentest.exe -url http://localhost:8080
# 6 — Verify any block signature with secp256k1
$ openssl pkeyutl -verify -pubin -inkey pub.pem ...
